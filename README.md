# 🧮문자열 덧셈 계산기

## 문제

---
> 입력한 문자열에서 숫자를 추출하여 더하는 계산기 구현한다.

- 쉼표, 콜론, 사용자가 지정한 커스텀 문자를 구분자로 한 문자열이 전달되었을 때 구분자를 기준으로 분리한 각 숫자의 합을 반환하도록 한다.


- 커스텀 구분자는 "//"와 "\n" 사이에 위치하는 문자이다. `//;\n1;2;3`과 같은 문자열이 입력되었을 때, 커스텀 구분자는 `;`가 된다.


## 기능 목록

---

**📍 문자열 입력**
- 사용자로부터 문자열을 입력받는다.

**📍 구분자 처리**
- 기본 구분자
  - 쉼표와 콜론을 구분자로 하여 문자열을 분리한다.
- 커스텀 구분자 
  - `//`와 `\n` 사이에 위치한 문자를 커스텀 구분자로 인식하여 문자열을 분리한다.

**📍 숫자 변환 및 검증**
- 분리된 문자열을 정수로 변환한다.
- 음수 또는 숫자가 아닌 값이 포함되어 있으면 `IllegalArgumentException`을 발생시킨다.

**📍 합 계산**
- 정수로 변환된 숫자들을 모두 더해 값을 계산한다.
